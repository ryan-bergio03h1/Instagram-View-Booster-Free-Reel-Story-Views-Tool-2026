### How to use

1. Launch the program  
2. Paste your Instagram Reel / Story / Video link  
3. Select a profile (Safe recommended)  
4. Set desired views amount  
5. Click **Start**

---

### Configuration

All settings are stored in `config/default.json` and profile files:

- Delivery speed  
- Views per hour limit  
- Safety delays  
- Proxy list  
- Target type (Reels / Stories / Videos)  
- Daily limits
